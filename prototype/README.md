# Glow インタラクティブ・プロトタイプ

`index.html` をブラウザで開くだけで動きます（ビルド不要・外部通信はGoogle Fontsのみ）。

- 全画面：年齢確認 / タグ選択 / フィード（縦スワイプ）/ 通報・コメント・シェアのシート / 外部遷移 / 探す / お気に入り / マイページ / 投稿 / ダッシュボード / 設定 / デザイン・テーマ / テーマのカスタマイズ
- テーマ：Midnight・Rose・Ocean・Emerald・Gold・Crimson・Minimal・Custom × ダーク/ライト/システム
- 動画はすべて抽象的なグラデーションのプレースホルダー
- データはすべてモック。状態はブラウザの localStorage に保存

設計の根拠は [docs/07_デザインシステム_テーマエンジン.md](../docs/07_デザインシステム_テーマエンジン.md) を参照。
フェーズ2以降の本実装（Next.js）では、ここで使っているトークンとテーマエンジンをそのまま移植します。
