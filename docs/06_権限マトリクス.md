# 06. 権限マトリクス

## ロール

| ロール | 説明 |
|---|---|
| 未同意 | 年齢ゲートに同意していない人（ログインの有無は関係ない） |
| 閲覧者（ゲスト） | 同意済みで、ログインしていない |
| 閲覧者（会員） | 同意済みで、ログインしている |
| 投稿者（承認済み） | `creator_profiles.status = approved`。申請中・却下・停止・BANの人は「会員」と同じ扱い（さらに投稿を禁止） |
| 審査担当 `reviewer` | 動画の審査、申請の審査、URLの審査 |
| 通報対応 `report_handler` | 通報、削除請求、不正フラグ |
| 本人確認担当 `identity_officer` | **本人確認書類を閲覧できる唯一の実務ロール**（Q2-3で、審査担当と兼ねるかを決めていただきます） |
| スーパー管理者 `super_admin` | すべての操作。ただし本人確認書類を見るときも閲覧ログが残る |

凡例：◎ できる　○ 条件つき　— できない

## 共通ルール
- 管理画面の操作は、**閲覧も含めて**すべて `admin_audit_logs` に追記します（一覧の閲覧はまとめて1行、詳細の閲覧と更新は1件ずつ1行）。
- 管理者は2段階認証（TOTP）が必須です。`allowed_ip_cidrs` が設定されている場合は、その範囲外からは403を返します。
- 管理者のセッションは操作がなければ30分で切れ、最長8時間で切れます。
- 本人確認書類の閲覧は「理由の入力 → ログに追記 → 60秒だけ有効なURL」の順でしか行えません。画面には閲覧者のIDを透かしで重ねて表示します。
- `super_admin` を2人以上置くことを推奨します（1人が抜けても運用を止めないため）。
