## フェーズ1 報告

### 1. 作ったもの
- 上の9本の設計書です。ER図・画面遷移図・Theme Engineの図はMermaidで書いてあるので、GitHub上でそのまま図として表示されます。
- 添付UI画像から読み取ったデザイントークンと、UIプロンプトの8テーマを合わせて、テーマを切り替えられる形のトークン設計にしました（07）。
- 機能要件A〜Gと閲覧者・投稿者・運営・不正対策・計測の各要件を、テーブル・API・画面・権限に割り当てました。対応表は01にあります。

### 2. 動作確認の方法
- 実装はまだないので、動かして確認するものはありません。
- GitHubで `docs/` を開くと、各Mermaid図が表示されます。
- 01の「要件トレーサビリティ表」で、すべての要件がどの設計で満たされるかを確認できます。

### 3. 未実装・仮のままの部分
- アプリのコードはすべて未実装です（フェーズ2以降）。
- 動画保存先の比較表（02）の**料金と、アダルトコンテンツの可否**は公開情報をもとにした初期評価です。各社の最新規約と見積もりは、契約前に原文で確認する必要があります。この作業はフェーズ2の最初に入れています。
- 法務ページの文面は、まだ構成だけを決めた段階です。雛形の文面はフェーズ8で作ります。

### 4. 次のフェーズで決めていただきたいこと
[09 質問リスト](./09_質問リスト.md) にまとめました。特に以下の5つは、決まらないとフェーズ2に入れません。
1. **リポジトリ**：このリポジトリ（MoodGo）とは別に新規リポジトリを作るか（推奨：別リポジトリ）
2. **ホスティング／DB／動画配信の組み合わせ**（推奨案は02の末尾）
3. **UIプロンプトと機能プロンプトで食い違う点**の扱い（タブ名、コメントアイコン、通報理由など）
4. **本人確認の方式**：書類の手動アップロードか、eKYC事業者に委託するか
5. **提供地域**：日本国内のみに限定するか（海外の年齢確認法への対応範囲が変わります）

### 5. 弁護士に確認すべき点
詳しくは [08 リスク一覧](./08_リスク一覧.md) の「法務」の節にあります。主なものは次のとおりです。
- 刑法175条（わいせつ物頒布等）：モザイクなど修整の基準と、審査で何を見るか
- AV出演被害防止・救済法：個人の投稿者が自分で撮った動画にも当てはまるか。同意書・公表までの期間・取消し請求への対応
- 児童ポルノ禁止法：未成年が疑われる場合の対応手順、警察への通報、証拠をどう保全するか
- ステルスマーケティング規制（景品表示法）：アフィリエイトリンクに「広告」「PR」の表示が必要か
- 情報流通プラットフォーム対処法・プロバイダ責任制限法：削除申出への対応と、発信者情報開示への対応
- 電気通信事業法：届出が必要か、外部送信規律（Cookieなどの公表義務）
- 個人情報保護法：本人確認書類の保存期間、委託先の監督、海外のサーバーに保存する場合の扱い
- 運営者を公開しない（問い合わせ窓口だけを載せる）構成が許されるか。将来、特商法表記が必要になる条件
- 自己申告式の年齢確認で足りるか
